# 🐉 Dragon Egg Hunter — Retro 8-Bit Pixel Shooter

> An action-packed, retro top-down pixel-art shooter built with modern HTML5 Canvas, featuring custom animal explorers, smart auto-aim, bilingual support (ID/EN), silky-smooth 60+ FPS rendering, and an epic multi-phase boss battle against a Red Dragon that evolves into a 3-Headed Rainbow Hydra!

---

## 🎮 Game Overview

**Dragon Egg Hunter** is a lightweight, single-file browser game where players choose their favorite animal explorer, fight through waves of forest and cave guardians, and face off against legendary dragon bosses to claim the ultimate **Legendary Dragon Egg**.

Designed with pure retro nostalgia, the game blends classic 8-bit arcade aesthetics with modern gameplay conveniences like Smart Auto-Aim, touch-friendly mobile controls, and crisp 60+ FPS offscreen canvas rendering.

---

## ✨ Key Features

1. **4 Unique Animal Explorers + Custom Outfits:**
   - **Fox Ranger:** Agile with rapid-fire capabilities.
   - **Owl Scout:** Equipped with accurate twin-shot projectiles.
   - **Bear Guard:** Heavy health pool and high-damage shots.
   - **Cat Rogue:** Lightning-fast movement and quick dash cooldowns.
   - **Real-Time Color Tints:** Customize your explorer's outfit with 6 retro color palettes (Crimson, Emerald, Azure, Amethyst, Arctic White, and Default).

2. **Epic 2-Phase Boss Battle:**
   - **Stage 1 & 2:** Navigate through *Ancient Woods* and *Obsidian Cavern*, dodging minion attacks (Slimes, Bats, Salamanders) and collecting power-ups.
   - **Stage 3 (Boss Fight):** Face the fierce **Crimson Dragon**. Defeat it to trigger a dramatic evolution sequence into the **3-Headed Rainbow Hydra** (Ruby Head, Emerald Head, Sapphire Head).

3. **Smart Auto-Aim & Accessibility:**
   - **Default Smart Auto-Aim:** Automatically locks onto the nearest enemy or Hydra head while you focus on movement and dodging.
   - **Bilingual Interface (`ID | EN`):** Switch instantly between Indonesian and English at any time during gameplay without resetting your progress.

4. **Silky-Smooth 60+ FPS Performance:**
   - Pre-rendered offscreen arena caching eliminates background stutter.
   - Delta-time physics ensures consistent animation speeds across all devices.

5. **Retro 8-Bit Audio & Blocky End Banners:**
   - Built-in Web Audio API synthesizer for retro sound effects (shooting, dashing, explosions, boss roars, and victory/game-over jingles).
   - Chunky 8-bit pixel art **VICTORY** and **GAME OVER** banners.

## 🚀 Quick Play & Installation

Because **Dragon Egg Hunter** is built entirely within a single HTML file (`dragon_egg_hunter.html`), no complex build tools, node modules, or external servers are required!

1. Download or clone the `dragon_egg_hunter.html` file.
2. Double-click the file to open it instantly in any modern web browser (Chrome, Firefox, Edge, Safari).
3. Choose your animal explorer, pick your outfit color, and click **START EXPEDITION!**

## 🛠️ Built With

* **HTML5 Canvas:** For high-performance pixel rendering.
* **Vanilla JavaScript (ES6+):** For game loops, physics, and input handling.
* **Tailwind CSS & Google Fonts ("Press Start 2P"):** For arcade UI framing and retro typography.
* **Web Audio API:** For programmatic 8-bit sound effects and chiptune jingles.
